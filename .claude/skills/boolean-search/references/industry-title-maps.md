## Tips for Using Title Maps

1. **Always include the generic title** - "Software Engineer" catches many candidates
2. **Include seniority prefixes** - Senior, Staff, Principal, Lead, Distinguished
3. **Include management titles** - Manager, Director, VP (for leadership roles)
4. **Consider abbreviations** - SRE, PM, ML, AI, UX, UI
5. **Check company-specific titles** - Google uses "Noogler", Meta uses "E5/E6", etc.
6. **Include emerging titles** - "AI Engineer", "Prompt Engineer", "Developer Experience Engineer"
7. **Consider international variations** - "Software Developer" (UK/EU), "Programmer" (some markets)
8. **Consider misspelling** - "sotware Developer, Enginer", etc.
